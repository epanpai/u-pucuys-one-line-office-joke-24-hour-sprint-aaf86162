Entry for the [One-Line Office Joke: 24-Hour Sprint](https://make.fun/bounty/u-pucuys-one-line-office-joke-24-hour-sprint-aaf86162) bounty on [make.fun](https://make.fun).

`main.ts` (Node 22, stdlib only) writes one original one-line joke about
office life to `/output/entry.txt`:

> The fire drill is the only meeting where everyone arrives on time and nobody takes notes.

89 characters — inside the 1–200 gate, a single sentence, no newline.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
